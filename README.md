## Overview

This repository contains lab work for **LAB 3** of the Computer Fundamentals & Career Pathways (CSE103) course at **K.R. Mangalam University**, Gurugram.

The project demonstrates practical Git and GitHub operations, repository management, version control, Markdown documentation and API interaction.


## Key Learning Outcomes

- Configured Git identity and initialised local repositories.
- Created atomic commits with meaningful Conventional Commit messages.
- Connected local repositories to remote GitHub repositories.
- Practised pushing and pulling changes with GitHub.
- Authored structured Markdown documentation.
- Explored version control and collaborative development workflows.
