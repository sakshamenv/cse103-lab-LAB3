# Markdown Syntax Guide

This document demonstrates the fundamental Markdown syntax used for creating professional documentation on GitHub.

## 1. Headings

Markdown supports different heading levels.

# Heading 1
## Heading 2
### Heading 3

## 2. Text Formatting

**This is bold text.**

*This is italic text.*

~~This is strikethrough text.~~

You can also combine formatting: **bold and *italic*.**

## 3. Unordered Lists

- Item A
- Item B
  - Nested item B1
  - Nested item B2
- Item C

## 4. Ordered Lists

1. First step
2. Second step
3. Third step

## 5. Inline Code

Use inline code to highlight commands or programming statements.

Example: `print("Hello World")`

## 6. Fenced Code Blocks

Use three backticks and specify the programming language for syntax highlighting.

Python example:

```python
def greet(name):
    return f"Hello, {name}!"

print(greet("Developer"))
```

Bash example:

```bash
git status
git add .
git commit -m "Initial commit"
git push
```

## 7. Hyperlinks

Markdown supports clickable hyperlinks.

[Visit GitHub](https://github.com)

[Learn Markdown](https://www.markdownguide.org/)

## 8. Tables

Markdown supports tables with different column alignments.

| Column 1 | Column 2 | Column 3 |
|----------|:--------:|----------:|
| Left | Centre | Right |
| Apple | Orange | Mango |
| Python | Java | C++ |

## 9. Blockquotes

Blockquotes are useful for highlighting important information.

> An important note or reference goes here.

> Markdown makes documentation easier to read and maintain.

## 10. Horizontal Divider

Use three hyphens to create a horizontal divider.

---

## Conclusion

Markdown is a simple and powerful language for creating structured documentation.

It is widely used in GitHub repositories, README files, technical documentation and developer blogs.
